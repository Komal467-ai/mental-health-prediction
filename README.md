# Student Mental Health Prediction

A machine learning project that predicts students' mental health scores using academic, lifestyle, and behavioral factors.

## 📌 Project Overview

This project uses machine learning to analyze factors such as study hours, sleep hours, physical activity, daily device usage, stress level, academic level, and other student-related attributes to predict the `Mental_Health_Score`.

## 📊 Dataset Features

The dataset contains information such as:

- Age
- Gender
- Country
- Academic Level
- Most Used Platform
- Purpose of Use
- Average Daily Usage Hours
- Daily Unlocks
- Study Hours
- Physical Activity Hours
- Sleep Hours per Night
- Stress Level
- Mental Health Score

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Google Colab
- Machine Learning
- Data Preprocessing
- Feature Engineering

## ⚙️ Machine Learning Approach

The project includes:

1. Data loading and exploration
2. Data preprocessing
3. Handling numerical and categorical features
4. Feature scaling and encoding
5. Train-test split
6. Machine learning model training
7. Model evaluation using:
   - R² Score
   - Mean Absolute Error (MAE)
   - Mean Squared Error (MSE)

## 🤖 Model

- Linear Regression

## 📈 Results

The model performance is evaluated on the test dataset using R² Score, MAE, and MSE.
